# Academic Paper Workflow Skills

Reusable Codex skills for an empirical journal-paper workflow.

Read [PRINCIPLES.md](PRINCIPLES.md) first: the author's working criteria that every skill follows.

## Available skills

In the order of a paper's life:

- `paper-ideation`: propose, verify and rank candidate topics; confirm one topic with its research question and data plan.
- `paper-literature-review`: collect, archive and read about one hundred full-text SCI/SCIE/SSCI papers; derive the gap statement, anchor-paper candidates and design revisions.
- `paper-data-collection`: inventory, clean and document the datasets; check the design's premises with exploratory analysis.
- `paper-data-analysis`: write the research design, implement the model, run the experiments in rounds and report results with the decisions the user must make.
- `paper-writing`: key-paper-guided, paragraph- and sentence-level manuscript writing and assembly.
- `paper-review`: section-by-section, minor-revision-scale submission review.

## Stage boundaries

Each skill ends with a deliverable the user confirms before the next skill starts, so writing and review do not silently redesign the study, recollect data or rerun analyses. Two lessons from use: the literature review of full texts comes before the design is frozen (an abstract-level prior-work table is not enough), and a draft written before the review is set aside and redone.
