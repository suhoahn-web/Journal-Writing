# Results documents, tables and figures

## Results document

1. Plain-language framing paragraph: what the paper asks, what the variable is, how it links to the user's field or brief.
2. Key numbers in a short table, in the field's unit.
3. Verdict per hypothesis, with the number that decides it.
4. New findings not anticipated by the hypotheses, stated as such.
5. Robustness summary.
6. Limitations and what is still empty.
7. Decisions for the user, each with a recommendation (main claim, appendix material, deferred experiments).

## Tables and figures

- Generated by scripts from the result files; no hand-typed numbers. A sanity assertion in the script (components sum to totals) catches editing errors.
- Follow the target journal's figure sizes and fonts from the start (width in millimetres, minimum font size, vector plus raster).
- Captions are self-contained; conventions and sample details go in notes; interpretation stays in the body.
- Check every number in the draft against the tables before the draft is called ready; a single inconsistent decimal is a reviewer's first comment.
