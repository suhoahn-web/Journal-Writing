# Collection and archiving

## Bibliography file

One row per paper: DOI, title, authors, year, journal, indexing (SCI/SCIE/SSCI/ESCI/none/unknown), stream, priority (1 must read, 2 should read, 3 optional), status (read / not obtained / context only / secondary candidate), version read, PDF file name.

## Obtaining full text

- Try in order: publisher open access, publisher HTML through a session the user has opened, author manuscript (institutional repositories), arXiv or SSRN, then the user's institutional download.
- Publisher sites block repeated automated access and show robot checks; open pages with intervals and never try to pass a robot check. A browser's own download prompt may ignore automated clicks and report nothing; verify that a file actually exists before reporting it saved.
- Files the user downloads land in the project's upload space; match them to DOIs by script (title and DOI inside the PDF), rename to the index convention, and keep the originals.
- Keep paywalled PDFs out of public repositories.

## Stop rule

After the automatic routes and one user list, stop trying. A paper that is important for the design or the draft goes on the must-have list with DOI, full title and the reason it matters. Everything else is skipped without further requests to the user. Uncited papers lose nothing; unverified citations lose the paper.

## Versions and verify flags

Record which version was read. Any number copied from an accepted manuscript, arXiv or working-paper version carries a verify flag in every later document until the published version is checked. Journals whose indexing is uncertain carry a verify flag until the Master Journal List is checked, which usually needs the user's account.
