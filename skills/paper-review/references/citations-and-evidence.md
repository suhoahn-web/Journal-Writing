# Citations and evidence

- Build bidirectional inventories: in-text citation to reference, and reference to in-text citation.
- Verify author, year, title, journal, pages/article number, and DOI from authoritative records.
- Read the full source passage supporting each material claim; title-only inference is prohibited.
- Confirm the citation supports the exact variable, direction, setting, and conclusion claimed.
- Identify secondary citations, duplicates, retractions, and fabricated or unresolved entries.
- Never invent a DOI or silently retain an inaccessible source.
- Replacement literature must be verified SCI, SCIE, or SSCI unless the user authorizes otherwise.
- If access fails, give the user the full title immediately. If it remains unavailable, propose a verified substitute and explain the claim-level fit.
